## Assumptions to test in the pilot

1. Decision time from disruption detection to an approved plan falls significantly against today's process.
2. Projected and observed outcomes (holding, ground waits, uncoordinated diversions) improve against local-only
   decisions on comparable nights.
3. Stakeholders accept scoped approval requests and the audit trail as part of their workflow.
4. Integration is feasible on-premises with existing A-CDM/AODB interfaces within the security constraints.
